# Stellar · Деканат — кабинет студента

Конкурсный прототип личного кабинета студента для хакатона **«Цифровой деканат будущего»**.
Это **учебный концепт, а не официальный сервис**: университет «Стеллар», студенты, преподаватели и оценки вымышлены.

**Живая версия:** https://stellarschool.ru/dekanat/

## Идея

Названия и расположение — как в обычном кабинете вуза (ориентир — Stellar School, см. [`docs/stellar-ux-notes.md`](docs/stellar-ux-notes.md)).
Разделы: **Главная · Расписание · Успеваемость · Заявки и справки · Уведомления · Профиль** и **Поиск** (Ctrl+K).

**Главная** — короткая: сверху истории деканата, затем «Требует внимания» (до трёх пунктов: ответ деканату,
готовый документ, долги, риски) и плитки «Ближайшее занятие», «Рейтинг», «Дедлайны», «Изменения», «Заявки» —
каждая ведёт в свой раздел.

**Расписание** — только расписание: строка недели и полоса дней, изменения прямо в карточке занятия
(«Перенос» / «Изменено» / «Отменено», старое значение зачёркнуто), экспорт в календарь — иконкой.
Все страницы компактные: одна карточка-список, второстепенное — под раскрытием.

В разделе «Успеваемость» каждая дисциплина — одна строка: баллы на шкале с порогом допуска (30), прогноз итоговой
оценки по текущим результатам, ближайшая сдача и состояние (в графике / внимание / риск).

Кроме того: калькулятор итоговой оценки, прогноз стипендии, трекер заявок в стиле доставки,
электронные справки с QR-проверкой и экспорт расписания в календарь (.ics).
Поиск (Ctrl+K) — палитра команд и ответы на простые вопросы по правилам на сервере, без внешних ИИ-сервисов.

## Дизайн

Система «Солнце» — яркий и дружелюбный стиль мобильного банка. Светлый фон, белые карточки с мягкими
тенями и скруглениями 16–24 px. Фирменный жёлтый (#FFDD2D) — только с чёрным текстом: основные кнопки,
активный пункт меню, карточка рейтинга. Цвета состояний (зелёный, охра, красный, синий) проходят WCAG AA.
Мобильная версия (360–390 px) — основная: нижняя панель из 5 пунктов (Главная, Расписание, Оценки, Заявки, Ещё),
«Ещё» открывает нижний лист с уведомлениями, профилем, поиском и выходом; на вложенных страницах в шапке кнопка «назад»;
главное действие («Новая заявка», «Отправить») — у большого пальца; все зоны нажатия не меньше 44 px; таблицы
превращаются в карточки; горизонтальная прокрутка — только у лент фильтров и новостей.
Шрифт Manrope (SIL OFL, с кириллицей, раздаётся с сервера), иконки lucide (ISC). Анимации 200–300 мс
без отскоков, `prefers-reduced-motion` учитывается. Логотип и стиль — собственные.

## Что умеет

- **Вход и профиль**: ФИО, факультет, направление, профиль, курс, группа, форма обучения; личные данные
  скрыты маской, активные сеансы можно завершить.
- **Расписание**: сегодня и неделя, аудитория и преподаватель, чётность недели, видимые замены, отмены и переносы
  (с указанием «откуда/куда»), сессия, экспорт .ics.
- **Успеваемость**: балльно-рейтинговая система (семестр 60 + экзамен 40, допуск ≥ 30), оценки и зачёты по
  контрольным точкам, темп и прогноз, «Что если…», зачётная книжка со средним баллом, долги, стипендия.
- **Заявки**: 9 типов (справки об обучении / для военкомата / о стипендии / справка-вызов, пересдача,
  индивидуальный план, матпомощь, академотпуск, вопрос). Статусы с историей и перепиской,
  ответ на запрос деканата, отмена, электронная справка с QR и публичной страницей проверки.
- **Уведомления**: новости, дедлайны, изменения расписания, статусы заявок; фильтры, «прочитать все».
- **Кабинет сотрудника**: входящие с KPI и фильтрами, карточка заявки, смена статуса с комментарием
  (студент получает уведомление), объявления для факультета, курса или группы.

## Стек

Как у основного сайта Stellar School: **React + Vite + Express + PostgreSQL** на TypeScript.
React 19, React Router 7, TanStack Query, собственная дизайн-система на CSS (без UI-кита),
иконки lucide (ISC), шрифт Manrope (SIL OFL, раздаётся с сервера).
Сервер: Express 5, pg, zod, bcryptjs, helmet, qrcode. Сервер собирается esbuild в самодостаточный файл.

## Запуск локально

```bash
cp .env.example .env        # заполнить DATABASE_URL, SESSION_SECRET, DATA_KEY; COOKIE_SECURE=0, NODE_ENV=development
npm ci
npm run migrate && npm run seed
npm run build && npm start  # http://127.0.0.1:4520/dekanat/
# или разработка: npm run dev:server  +  npm run dev:client
```

## Проверки

```bash
BASE=https://stellarschool.ru/dekanat node tests/security.test.mjs   # изоляция данных, CSRF, роли, cookie
BASE=https://stellarschool.ru/dekanat OUT=screenshots node tests/screenshots.mjs   # 360/390/768/1440, все роли
```

Скриншот-тест сам ищет горизонтальную прокрутку, выход элементов за экран или панель, обрезанный текст
и ошибки в консоли и пишет `_problems.json`.
