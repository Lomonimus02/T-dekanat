# Журнал работы (ИИ-агент + человек)

Работа выполнена ИИ-агентом по заданию владельца сервера; все шаги на сервере — через SSH, сборка — на машине агента.

## Этапы

1. **Разведка сервера** (только чтение). Ubuntu 24.04, 1 CPU, ~1 ГБ RAM (своп уже занят), PostgreSQL 16,
   Caddy на 80/443 (сайты в `/etc/caddy/sites/*`), pm2 под root. Найден сайт Stellar School
   (`/var/www/stellar`, pm2 `stellar`, домен stellarschool.ru) и посторонние проекты (altair, dejaview, webhook).
   Выяснено, что Stellar деплоится из GitHub с `git reset --hard`.
2. **Решение об основе.** Не встраивать кабинет в код Stellar (его перезапишет деплой, это рабочая школьная
   система с реальными пользователями, а по условиям нужны только вымышленные данные). Взять у Stellar стек,
   архитектуру, бренд и палитру; открыть кабинет на том же домене по пути `/dekanat`.
   Поддомены stellarschool.ru не резолвятся — поэтому путь, а не поддомен.
3. **Резервные копии** до любых изменений: код Stellar, дамп БД Stellar, конфигурация Caddy (`/root/backups/*_pre_dekanat*`).
4. **Концепция (первая версия).** Агент предложил визуализацию семестра в виде «звёздной карты» с ползунком времени.
   ИИ-помощник сознательно второстепенный и без внешних сервисов (правила на сервере).
5. **База и сервер**: схема, миграции, вымышленный сид с датами относительно дня запуска; API студента,
   сотрудника и публичный; безопасность (сессии, CSRF, лимиты, шифрование ПДн, проверки владения в SQL).
6. **Клиент**: собственная дизайн-система, 16 экранов, мобильная навигация, палитра команд.
7. **Визуальный QA**: скрипт снимает все страницы на 360/390/768/1440 для трёх ролей и автоматически ищет
   горизонтальную прокрутку, выход за экран или панель, обрезанный текст, прокрутку переключателей и ошибки консоли.
   Скриншоты просматривались вручную, найденное исправлялось, цикл повторялся.
8. **Тест безопасности**: 29 проверок (API и URL в браузере).
9. **Деплой**: отдельная БД и роль, `.env` (600), pm2 с автозапуском, блок `handle` в Caddy с `caddy validate`
   и плавным `reload`, проверка что stellarschool.ru и остальные сайты отвечают как прежде; ночное обновление демо-данных.
10. **Разворот по решению владельца.** Отзыв: дизайн «как у ИИ», звёздная карта странная и не нужна; нужен угловатый,
    блестящий, чистый и гармоничный дизайн с острыми углами. Сделано:
    - звёздная карта, ползунок времени и вся связанная лексика удалены из интерфейса, ответов «Штурмана» и документации;
    - на её месте — таблица «Дисциплины семестра» (баллы со шкалой и порогом допуска, прогноз, ближайшая сдача, состояние),
      API `/home` отдаёт `subjects` вместо данных карты;
    - новая дизайн-система «Лак и сетка»: радиусы 0, срезанные углы clip-path, тонкие линии, строгая сетка, чёрный
      глянцевый лак, один красный акцент, крупные цифры; шрифты Inter Tight / Inter / JetBrains Mono (SIL OFL, с кириллицей,
      самостоятельный хостинг), иконки с квадратными окончаниями; страница входа и логотип перерисованы;
    - строгий QA на проде: 3 роли × 4 ширины, все скриншоты просмотрены, тест безопасности повторён.

11. **Второй разворот по решению владельца.** Отзыв на угловатый дизайн: «ужасно, переделай, сделай нормальный».
    Владелец выбрал направление «яркий и дружелюбный, как приложение Тинькофф или Revolut» и уточнил: «сделай жёлтый дизайн».
    Сделано:
    - дизайн-система «Солнце»: светлый фон, белые карточки с мягкими тенями, скругления 16–24px, фирменный жёлтый
      только с чёрным текстом, крупные цифры, цветные плитки иконок; шрифт Manrope (SIL OFL, с кириллицей, свой хостинг);
      логотип, фавикон, страница входа и проверка документа перерисованы (без чужих логотипов и фирменных материалов);
    - на главной: «истории» деканата с полноэкранным просмотром (отмечают новость прочитанной), жёлтая карточка рейтинга,
      карточка следующей пары, быстрые действия; блок «Дисциплины семестра» сохранён; API `/home` отдаёт `stories`
      (только новости, видимые этому студенту);
    - на телефоне — нижняя панель как в нативном приложении, фильтры заявок сотрудника — горизонтальная лента;
    - QA на проде: 3 роли × 4 ширины + публичная страница проверки, все скриншоты просмотрены, тест безопасности повторён.

12. **Логика расположения и названий (ориентир — Stellar School).** Отзыв владельца: «элементы расположены не очень
    логично, некоторые названы странно; посмотри, как сделано на Stellar School, и адаптируй под телефон — это обязательно».

      «Что заказано» → «Данные заявки», «Переписка и история» → «История и сообщения», «Заказать» → «Оформить заявку»,
      «В календарь» → «Экспорт в календарь», «Скоро сдавать» → «Ближайшие дедлайны», «Что если…» → «Калькулятор итоговой

      «Ход заявки» → «Статус заявки», «Поля заявки» → «Данные заявки»; надписи-«брови» («Учёба», «Документы и связь»,

      «Следующая пара» (вошла в «Расписание на сегодня»), полная таблица дисциплин на главной (осталась в «Успеваемости»,

## Ключевые промпты и решения

- Исходное задание владельца: «сайт stellarschool взять за основу… красиво, с изюминкой, ИИ-агент может быть,
  но не основным… интерфейс супер уникальный, без визуальных багов».
- «Не ломать другие сайты» → только аддитивные изменения: новая БД, новый процесс pm2, новый блок Caddy, новый cron-файл.
- Сервер слабый → сборка на машине агента, сервер собирается esbuild в самодостаточный файл без `node_modules`,
  лимит памяти процесса.

## Ручные шаги

- Владелец передал доступ к серверу; агент добавил свой SSH-ключ в `authorized_keys` root и дальше работал по ключу.
  **После конкурса стоит сменить пароль root и удалить этот ключ.**
- Публикация репозитория на GitHub не выполнялась — репозиторий готов к публикации (секретов нет).
