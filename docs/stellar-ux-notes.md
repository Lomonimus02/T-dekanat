# Как устроен интерфейс Stellar School — заметки для кабинета деканата

Источник: код клиента на сервере (`/var/www/stellar/client/src`: `App.tsx`, `components/layout/*`, `pages/dashboard.tsx`,
`components/dashboard/*`, `pages/grades.tsx`, `pages/profile.tsx`). Чужие аккаунты не использовались, данные не менялись.

## Навигация
- Боковое меню на компьютере — плоский список разделов, подписи — обычные существительные:
  «Главная», «Поиск», «Расписание», «Оценки», «Домашние задания», «Сообщения», «Документы», «Профиль», «Настройки», «Поддержка».
  Нет придуманных названий: раздел называется тем, что в нём лежит.
- «Поиск» — отдельный пункт меню (открывает глобальный поиск), а не персонаж-помощник.
- Состав меню зависит от роли; у ученика — Главная, Расписание, Домашние задания, Оценки.
- На телефоне — плавающая нижняя «таблетка» с 4–5 главными разделами и отдельная круглая кнопка меню,
  которая открывает полный список. Панель прячется при прокрутке вниз, у пунктов минимум 44px по высоте.

## Анатомия страницы
1. Заголовок страницы (`h1`, `data-page-title`) слева + короткий подзаголовок: «Панель управления» /
   «Добро пожаловать, Имя Фамилия». Кнопки действий — справа от заголовка (на телефоне — под ним).
2. Ряд карточек-показателей (StatCard: число + подпись) — только там, где числа полезны.
3. Вкладки и фильтры (Tabs, Select «Период») — сразу под заголовком, до содержимого.
4. Содержимое — карточки с простыми заголовками: «Расписание на сегодня», «Личные данные», «Документы», «Средний балл».
5. Пустые состояния — прямым текстом: «Нет занятий на сегодня».

## Главная ученика
- Сначала «Расписание на сегодня» (2/3 ширины), справа — уведомления и домашние задания.
- На телефоне — одна колонка в порядке важности: расписание → задания.
- Никаких дублей навигации на главной: в другие разделы ведут меню и ссылки «Все…» в карточках.

## Что берём в кабинет деканата
- Простые названия разделов и блоков, «Поиск» вместо «Штурмана», «Главная» вместо «Пульта».
- Одна анатомия для всех страниц: заголовок + подзаголовок → главное действие → вкладки/фильтры → содержимое → пустое состояние.
- Главная по приоритету задач студента: расписание на сегодня → изменения и дедлайны → успеваемость → мои заявки → новости.
- Телефон: нижняя панель из 5 пунктов, последний — «Ещё»; на вложенных страницах в шапке кнопка «назад»;
  все нажимаемые элементы ≥ 44px; главное действие — у большого пальца (внизу экрана).
